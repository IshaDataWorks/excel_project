# 🍽️ Zomato Data Analysis – Excel Dashboard 

## 📌 Project Overview

This project focuses on analyzing **Zomato's order, customer, restaurant, city, and menu data** using **Microsoft Excel**.

The objective is to transform raw data into meaningful business insights and build an **interactive Excel dashboard** that helps understand order trends, customer behavior, restaurant performance, and revenue patterns.

---

## 🎯 Business Problem

Zomato operates across multiple cities with thousands of customers, restaurants, and menu items. The company needs to understand its business performance to identify trends, improve customer experience, and make data-driven decisions.

This project analyzes the available data to answer important business questions related to **orders, revenue, customers, restaurants, cities, and menu items**.

---

## 🎯 Project Objectives

* Analyze overall business performance using key metrics.
* Identify top-performing restaurants and cities.
* Analyze customer purchasing behavior.
* Identify best-selling menu items.
* Analyze revenue and order trends.
* Calculate Average Order Value (AOV).
* Identify high-value customers.
* Build an interactive and easy-to-understand Excel dashboard.

---

## 📊 Key Business Questions

1. Which restaurants generate the highest revenue?
2. Which restaurants receive the most orders?
3. Which cities contribute the highest revenue and number of orders?
4. Which menu items are the best-selling?
5. Who are the most valuable customers?
6. What are the monthly order and revenue trends?
7. What is the Average Order Value?
8. How does customer ordering behavior vary across different segments?

---

## 🗂️ Dataset

The project uses multiple related datasets containing information about:

* **Orders** – Order details, dates, customers, restaurants and order values.
* **Order Items** – Individual items included in each order.
* **Customers** – Customer information and purchasing activity.
* **Restaurants** – Restaurant details and performance.
* **Menu** – Menu items, categories and prices.
* **City** – City-level information.
* **Date** – Date-related information used for trend analysis.

> Note: Delivery partner data was not included in the final dashboard analysis because there was no suitable relationship with the other tables.

## 🧹 Data Cleaning & Preparation

The raw datasets were prepared in Excel before analysis.

The major data-cleaning steps included:

* Removing duplicate records.
* Handling missing values.
* Checking and correcting data types.
* Standardizing text values.
* Checking date formats.
* Validating numerical columns.
* Creating calculated fields required for analysis.
* Preparing data for Pivot Tables and dashboard analysis.

## 📈 Key KPIs

The dashboard includes important business KPIs such as:

* **Total Revenue**
* **Total Orders**
* **Total Customers**
* **Average Order Value (AOV)**
* **Top Restaurant by Revenue**
* **Top City by Revenue**
* **Top-Selling Menu Items**

### Average Order Value

**AOV = Total Revenue ÷ Total Orders**

This metric helps measure the average amount spent per order.
